# 🔬 AI Research Assistant

An AI-powered research agent built with **Claude (Anthropic)**, **Tavily web search**, and a **Model Context Protocol (MCP) filesystem server**. Enter any research topic and receive a structured, cited research report — exportable as `.txt` or `.pdf`.

---

## ✨ Features

- **Live Web Search** via Tavily API for up-to-date context
- **Streaming AI Reports** generated by Claude with inline citations
- **Prompt Caching** on system prompt and web context for faster, cheaper repeated queries
- **MCP Filesystem Integration** — the Document Library is powered by the `@modelcontextprotocol/server-filesystem` MCP server
- **Export Options** — download reports as `.txt` (cleaned plaintext) or `.pdf` (formatted)
- **Document Library** — sidebar listing of all past reports with download and delete support
- **Graceful Fallback** — if the MCP server is unavailable, the app falls back to direct filesystem access and surfaces a warning

## 🚀 Setup & Installation

### 1. Clone the Repository

```bash
git clone https://github.com/24f3003329/ai-intern-final-yadav-ankit-brajmohan.git
cd ai-intern-final-yadav-ankit-brajmohan
```

### 2. Create a Virtual Environment (Recommended)

```bash
python -m venv venv

# macOS / Linux
source venv/bin/activate

# Windows
venv\Scripts\activate
```

### 3. Install Python Dependencies

```bash
pip install -r requirements.txt
```

### 4. Configure API Keys

Create a `.env` file in the project root:

```env
ANTHROPIC_API_KEY=your_anthropic_api_key_here
TAVILY_API_KEY=your_tavily_api_key_here
```

**Get your keys here:**
- Anthropic: [console.anthropic.com](https://console.anthropic.com/)
- Tavily: [app.tavily.com](https://app.tavily.com/)

### 5. Create the Agent Package Init (if missing)

```bash
touch agent/__init__.py
```

### 6. Verify Node.js is on your PATH (required for MCP)

```bash
node --version   # v18.x or higher
npx --version
```

## 🧪 How to Use

1. Enter a topic in the text input (e.g. `"Quantum Computing advancements in 2026"`)
2. Click **Generate Research Report**
3. The agent will:
   - Search the web via Tavily for live context
   - Stream a structured, cited report via Claude
4. Download the report as **TXT** or **PDF** from the export section
5. All past reports appear in the **Document Library** sidebar — download or delete from there

## 🔌 MCP Integration Details

The Document Library sidebar is powered by the [`@modelcontextprotocol/server-filesystem`](https://github.com/modelcontextprotocol/servers/tree/main/src/filesystem) MCP server.

**How it works:**

- `agent/mcp_filesystem.py` — manages the full MCP server lifecycle as an async context manager. It launches the server as a Node.js subprocess via `npx`, performs the protocol handshake, exposes tool calls, and tears down cleanly on exit. The server is scoped to the absolute path of the `exports/` directory to avoid permission errors on Windows.

- `agent/mcp_client.py` — wraps the async MCP calls in synchronous functions using `asyncio.run()`, making them safe to call directly from Streamlit's synchronous execution model.

**MCP tools used:**

| Tool | Where used |
|---|---|
| `list_directory` | Sidebar — fetches the list of exported reports |

**Note on delete:** The `@modelcontextprotocol/server-filesystem` server intentionally does not expose a delete tool — destructive operations are excluded from its API by design. File deletion is handled via `os.remove` as the correct fallback.

**To verify MCP is live without the UI:**

```bash
python -c "from agent.mcp_client import list_reports; print(list_reports())"
```

## 🛠 Troubleshooting

**`TAVILY_API_KEY` missing error on startup**
→ Ensure `.env` exists in the project root with the correct key name.

**Claude API model error**
→ Check the model string in `agent/claude_client.py` against [docs.anthropic.com/models](https://docs.anthropic.com/en/docs/about-claude/models).

**MCP server unavailable warning in sidebar**
→ Confirm Node.js ≥ 18 is installed and `npx` is on your PATH. Test with:
```bash
npx -y @modelcontextprotocol/server-filesystem --help
```

**PDF export encoding error**
→ Add the offending character to `LATIN1_CHAR_MAP` in `agent/exporter.py`.
